# 03 — Кормление

## Цель

Ребёнок готовит еду из ингредиентов и кормит котёнка. Результат сохраняется после перезапуска.

## Задачи

- [x] Кухня: выбор 2–4 ингредиентов, поочерёдная мойка, нарезка, жарка, украшение и подача.
- [x] Убрать быстрый обед из комнаты и навигации; сохранить чтение старого прогресса.
- [x] Эффекты ингредиентов и точных рецептов, +6 монет только при сытости до еды < 60.
- [x] Плита: ползунок включения и температуры, продукты в сковороду, перемешивание пальцем на сковороде. Жёлтая зона не готовит, зелёная готовит со звуком шипения, красная превращает еду в угольки и списывает продукты.
- [x] Сохранение ингредиентов, готовой еды, монет и открытых рецептов; XCTest и проверка сборки.
- [x] Заменить неприятную синтезированную реплику на тихий натуральный звук котёнка при кормлении.
- [x] Два ползунка воды и индикатор температуры: мойка только в зелёной зоне; звуки открытия крана и текущей воды.
- [x] Смягчить звук воды, добавить тихую фоновую музыку и бесплатную заглушку пополнения продуктов на полке.
- [x] Полные миски с отдельными иллюстрациями шести рецептов; для произвольных сочетаний вариант готового блюда выбирается по продуктам без значков сырых ингредиентов.
- [ ] Проверить полный сценарий на устройстве.

## Критерий приёмки

- Новый котёнок может пройти кухню до появления магазина.
- Блюдо проходит все шаги С1 и даёт эффекты ингредиентов; совпавший рецепт запоминается.
- Монеты за кухню начисляются только при сытости ниже 60 до еды.
- Подгоревшее блюдо видно как угольки; потраченные ингредиенты исчезают из запасов сразу, монеты и шкалы не меняются.
- Запасы и результат кормления переживают перезапуск.

## Вне этой задачи

Магазин, полная книга рецептов, реклама R1/R2 и дополнительные готовые блюда.
