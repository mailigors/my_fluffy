# 01 — Каркас и пересчёт потребностей

## Цель

Собрать iOS-проект «Мой питомец» и чистый расчёт пяти шкал по реальному времени. Экранов нет.

## Задачи

- [x] Разложить правила агента из `cursor/` в `.cursor/`.
- [x] Завести Xcode-проект: только iPhone, портрет, iOS 15, язык Swift 5, таргеты приложения и XCTest.
- [x] Реализовать offline-decay: скорости режима «большой», множитель «малыш» ×0,6 только на падение, потолок 8 часов, зажим 0…100, красная зона.
- [x] Покрыть расчёт тестами.

## Критерий приёмки

- `MyFluffyTests` проходят на симуляторе: падение сытости, чистоты, настроения и энергии; наполнение туалета без множителя «малыш»; потолок 8 часов с записью `lastCalculated = now`; зажим 0 и 100; границы красной зоны.
- Файл расчёта не импортирует SwiftUI.
- В проекте нет экранов комнаты, кухни и мини-игр.

## Вне этой задачи

Сон, ласка, рецепты, монеты, реклама, SwiftData, онбординг, вёрстка. Показ иконки лотка при туалете > 70 — вместе с экраном комнаты.
