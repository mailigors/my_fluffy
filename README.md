# Мой питомец Мурзик

Детская игра для iPhone. Источник чисел и сценариев — [concept/gdd.md](concept/gdd.md). Файлы в `knowledge/` — выжимка для работы. Если они расходятся с концепцией, верна концепция.

Проект Xcode — `MyFluffy.xcodeproj`. Правила агента — в `.cursor/`. В проект «Война Слов» этот каталог не подключать.

## Раскладка

`concept/`, `knowledge/` и `documents/` лежат в корне. Правила, хуки и навыки агента — в `.cursor/`. Словарь, мультиплеер и межстраничная реклама из «Войны Слов» сюда не входят.

## Стек

iOS 15.0+, только iPhone, портрет. Swift 5.9, SwiftUI и SpriteKit через `SpriteView`. MVVM. На iOS 15 состояние экрана — `ObservableObject` / `@Published`, не `@Observable`. Настройки — `UserDefaults` (`@AppStorage`). Состояние питомца — SwiftData, запасной путь — Core Data. StoreKit 2. Реклама — только rewarded, детская (G, `tagForChildDirectedTreatment`). Аналитика — Firebase без персонализации и без IDFA. Логика потребностей, рецептов и лимитов рекламы — без SwiftUI, сразу с XCTest. Без `try!` и force unwrap. Текст интерфейса — `String(localized:)`, русский. Звук — локальные файлы, `AVAudioSession` категории `.ambient`.

## Границы версий

Подэтапы и проверка каждого — в [documents/function_registry.md](documents/function_registry.md). На этап не больше пяти.

**MVP.** Онбординг и имя, комната, потребности С1–С7 (лечение С6 в MVP по дорожной карте ТЗ не входит в полный вид — см. ниже), магазин на 12 товаров, мини-игры С8, С9, купание С3 и туалет С4, реклама R1–R6, локализация RU.

Уточнение по ТЗ: таблица дорожной карты кладёт ветеринара (С6) в v1.1, а в состав MVP пишет «5 потребностей (С1–С7)». Пока дизайн не разрежет это явно, в MVP входят кормление, быстрая еда, купание, туалет, сон и ласка (С1–С5, С7). Болезнь и кабинет ветеринара — v1.1.

**v1.1.** Ветеринар (С6), кухня со всеми рецептами, игротека (С10), достижения, ивент «День рождения».

**v1.2.** Система ивентов, синхронизация iCloud, виджет «покормить», английская локализация.

## Процесс агента

Одна задача — один `documents/backlog/*_work.md`. Карта функций — `documents/function_registry.md`. Ревьюер запускается только followup-хуком `stop` после правок исходников. Ask, Plan и чтение файлов ревью не запускают. Правила в `.cursor/rules/` меняются только фразами «принять правило N», «принять все», «отклонить N».

Сборка и проверка жестов, StoreKit и рекламы — на устройстве. Симулятор годится для вёрстки.
