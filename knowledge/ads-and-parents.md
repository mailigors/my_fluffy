# Реклама и родительская зона

Источник — [concept/gdd.md](../concept/gdd.md), разделы 2.8, 3.6, 3.8. Учёт лимитов только на устройстве, сброс в локальную полночь. Серверного счётчика нет.

## Сценарии

| ID | Когда кнопка | Награда | Лимит в сутки |
|----|--------------|---------|---------------|
| R1 | кухня, шаг «Пожарь», блюдо ещё готовится | готово сразу | 3 |
| R2 | на полке не хватает ингредиента выбранного рецепта | +1 этот ингредиент | 2 |
| R3 | открыт календарь | сундук ×3 (+30 и стикер) | 1 |
| R4 | итог мини-игры | продолжить с тем же счётом | 2 |
| R5 | активна болезнь | выздоровление без мини-игры | 1 |
| R6 | окно результата любой заботы | монеты ×2 | 3 |
| R7 | в гардеробе наряд не куплен | примерка 60 мин | 2 |
| R8 | вкладка «Комната» | товар бесплатно | 1 раз в 2 дня |
| R9 | в книге есть закрытые рецепты | случайный рецепт | 1 |

Кнопка приза отдельно от основного действия: радужная обводка, пиктограмма подарка, подпись-пиктограмма «посмотри — получи». Перед роликом — картинка «Смотрим?» с да и нет. Если ролик не загрузился за 3 секунды, кнопка пропадает без сообщения об ошибке. Награда только после `didEarnReward`, один раз на `adNonce`. Закрытие ролика — только крестиком, не по таймеру.

В тихий час (интервал из родительской зоны) кнопки R1–R9 скрыты.

## «Без рекламы»

StoreKit 2, продукт около $2,99, восстановление покупок. Статус только из `Transaction.currentEntitlements`. Флаг `adsDisabled`: SDK не инициализируется, кнопки ролика скрыты. Награды R1–R9 остаются по **одному** разу в сутки бесплатно, чтобы покупка не отбирала награды. Лимиты «с роликом» при этом не действуют.

Родитель может выключить отдельные сценарии R1–R9. Выключенный сценарий не показывает кнопку.

## SDK

Google Mobile Ads 11+, `GADRewardedAd`. `tagForChildDirectedTreatment = true`, `maxAdContentRating = G`, сеть certified-for-kids. Медиации в v1 нет. Предзагрузка при входе в сценарий, в кэше один ролик на сценарий. Unity Ads допустим только в kid-safe конфигурации, если AdMob не выбран. Не добавлять межстраничную рекламу и баннеры.

## Родительская зона

Вход: удержание кнопки 3 секунды, затем вопрос «7 + 5» с четырьмя вариантами. Внутри: статистика (монеты, время за день и неделю, число показов), переключатели R1–R9 и тихий час, возраст «малыш» / «большой», три ползунка громкости и выключатель озвучки, смена имени, покупка «Без рекламы», сброс прогресса с двумя подтверждениями. Сброс удаляет все хранилища состояния.

Детский UI не ведёт в эту зону одной кнопкой без удержания и примера.
