# «Мой питомец Мурзик» — детальная концепция и техническое задание

Документ для команды разработки. Версия 1.0, для iPhone, дети 3–7 лет.

---

## Часть 1. Видение продукта

### 1.1. Позиционирование

Виртуальный питомец для самых маленьких: первая игра, в которой ребёнок учится заботе — кормить, мыть, лечить, убирать — без страха ошибки и без навязчивых покупок. Игра, которую родители советуют друг другу.

### 1.2. Ключевые ценности

- **Безопасность**: нет открытого интернета, нет переписки, нет страшных сцен, нет агрессивного доната.
- **Забота как геймплей**: все механики — это акты заботы; ребёнок не «играет ради очков», а «помогает другу».
- **Доступность**: один палец, нет чтения (весь интерфейс — пиктограммы и озвучка), сессии 2–5 минут.

### 1.3. Целевая аудитория

- **Основная**: дети 3–5 лет (детский сад) — играют сами, родители рядом первые 2–3 запуска.
- **Дополнительная**: дети 6–7 лет (подготовка к школе) — самостоятельно, любят коллекционировать рецепты и наряды.
- **Покупатель**: родители. Продающие аргументы: обучение заботе и гигиене, без рекламы между игрой (только добровольная), без встроенных покупок в детской зоне, русская озвучка.

### 1.4. Уникальное торговое предложение (USP)

Единственная игра-питомец, где полный цикл заботы — от приготовления еды из ингредиентов до уборки лотка и визита к ветеринару — раскрыт как детские мини-игры, а не как кнопки с таймером.

### 1.5. Успех продукта (метрики через 3 месяца)

| Метрика | Цель | Как измеряем |
|---------|------|--------------|
| Retention D1 | ≥ 45% | аналитика (анонимная, возрастная группа) |

## Часть 2. Гейм-дизайн

### 2.1. Персонаж

**Котёнок Мурзик** (имя по умолчанию, меняется ребёнком).

- **Внешность**: рыже-кремовый, большие тёмные глаза, маленький розовый носик, пушистый хвост. Стиль — «наклейка»: толстый коричневый контур, мягкая заливка.
- **Состояния-спрайты** (анимированные):
  1. Обычное (idle): сидит, моргает, подрагивает ушами, иногда чешется.
  2. Счастливое: кувыркается, машет лапой, из груди — сердечки.
  3. Голодное: облизывается, смотрит на миску, «бурчит» животом (иконка 🍖 над головой).
  4. Грязное: серые брызги на шерсти, чешется, иконка 🫧.
  5. Скучное: лежит на боку, зевает, иконка 😊.
  6. Сонное: клюёт носом, полуприкрытые глаза, иконка ⚡.
  7. Хочет в туалет: сидит, прижимает лапы, иконка 🚽.
  8. Больное: лежит, зелёный носик, иконка 🌡.
  9. Спит: лёжа, «Z-z-z».
  10. Ест: за миской, хвостом довольно бьёт.
- **Звуки**: мяуканье (6 вариантов), мурчание (петля), храп, чих при болезни, довольное «мрр-мяу».

### 2.2. Потребности (5 шкал)

Каждая шкала 0–100. Скорость падения указана для режима «большой» (6–7 лет); в режиме «малыш» — ×0,6.

| Потребность | Падение | «Красная зона» | Иконка | Действие |
|-------------|---------|----------------|--------|----------|
| Сытость 🍖 | −1 / 5 мин | < 30 | еда | кормление через готовку |
| Чистота 🫧 | −1 / 6 мин | < 30 | пена | купание (мини-игра пузыри) |
| Настроение 😊 | −1 / 7 мин | < 30 | мячик | мини-игры, ласка |
| Энергия ⚡ | −1 / 10 мин | < 25 | полумесяц | сон |
| Туалет 🚽 | +1 / 2 мин (наполнение) | > 70 | лоток | сценарий лотка |

- Показатели считаются по реальному времени (offline-decay): при возвращении в игру пересчёт по формуле `elapsed_min × rate`.
- Шкалы отображаются только при < 70 (плавно появляются), чтобы не перегружать экран.
- При < 30: питомец грустит, играет пассивную грустную анимацию, над головой мигает иконка нужды; доступны только соответствующие действия.

### 2.3. Сценарии заботы (описаны полностью)

#### С1. Кормление через кухню (основной)

1. Тап по иконке еды → экран готовки без названия комнаты.
2. Полка с 8 ингредиентами (см. 2.5). Ребёнок нажимает 2–4 продукта, они появляются в миске.
   Пока рекламный SDK не подключён, отдельная кнопка подарка на полке позволяет бесплатно пополнять выбранный продукт на 3 штуки. Это временная заглушка, чтобы запас не закончился во время разработки.
3. Шаг «Помой»: ползунками слева и справа открыть холодную и горячую воду, настроить температуру до зелёной зоны индикатора, затем по очереди потереть каждый продукт в раковине до полного индикатора чистоты. Синяя вода слишком холодная, красная слишком горячая — продукт отмывается только тёплой водой. Открытие крана и текущая вода звучат отдельно.
4. Шаг «Порежь»: нажать на каждый продукт, после чего 3 кусочка отскакивают.
5. Шаг «Пожарь»: сдвинуть ползунок плиты из положения «Выкл», положить продукты в сковороду, водить лопаткой по сковороде. Жёлтая зона не готовит, перемешивание в зелёной превращает продукты в блюдо и сопровождается тихим шипением, красная превращает продукты в угольки. Сгоревшие ингредиенты сразу списываются из запасов; после этого можно начать заново.
6. Шаг «Укрась»: 6 посыпок-стикеров (звёздочки, сердечки, радуга), тап по одной украшает блюдо.
   Вид блюда зависит от выбранных ингредиентов: точные рецепты имеют отдельные иллюстрации, для остальных сочетаний выбирается подходящая полная миска с готовой едой. Значки исходных продуктов поверх готового блюда не показываются.
7. Тап по блюду → перенос в комнату → котёнок ест 3 секунды с тихим кошачьим звуком, шкала сытости += Σ эффектов ингредиентов (см. 2.5), монетки +6 (если сытость была < 60).
8. Блюдо записывается в «Книгу рецептов» (уникальная комбинация → новый стикер-рецепт).

#### С2. Быстрое кормление — отменено

По решению пользователя отдельный экран и кнопка быстрого кормления убраны. Старое поле готовых порций в сохранении остаётся только для совместимости с предыдущими версиями.

#### С3. Купание

1. Тап по 🫧 → ванная: Мурзик в пене, по экрану плавают 8–12 пузырей.
2. Тап по пузырю → лопается (звук «плюх», брызги) +4 к чистоте.
3. Все пузыри лопнуты → душ: свайп сверху вниз 3 раза — вода смывает пену.
4. Полотенце: трение кругообразное 2 секунды — шерсть становится пушистой.
5. Мурзик трясётся, вылетают звёздочки, +6 монет, шкала чистоты = 100.

#### С4. Туалет

1. При шкале туалета > 70: Мурзик беспокоится, иконка лотка мигает. Тап → экран уголка.
2. Мурзик заходит в лоток, анимация «дела», звук-шутка («плюм-плюм»), из лотка вылетают жёлтые «звёздочки запаха».
3. **Мини-игра «Чистый уголок» (2 шага)**:
   - a. Совок притягивается к пальцу: ребёнок ведёт его по полу, собирая 3–4 «комочка» (они притягиваются к совку с магнитным эффектом радиусом 60 pt). Собраны все → совок сам высыпает в лоток.
   - b. Следы лапок на плитке: губка размером с палец; свайп по следу — след исчезает со «скрипом» (haptics light). 4 следа.
4. Лоток сияет, цветочек рядом качается, +6 монет, шкала туалета = 0.

#### С5. Сон

1. Тап по ⚡ (или по лежанке) → подтверждение-картинка «Уложить спать?» (луна).
2. Комната плавно темнеет (2 сек), окно показывает ночное небо со звёздами, Мурзик сворачивается на лежанке, «Z-z-z».
3. Пока спит: энергия +4 / 5 сек (только пока игра открыта; при выходе из игры энергия восстанавливается до 100 за 10 минут реального времени, не более).
4. Тап по Мурзику → просыпается (потягушки, «мяу!»), день. Награды нет; сон — не «задание», а состояние.

#### С6. Лечение (событие «Болезнь»)

**Триггер**: (чистота < 15 и не купали 2 часа) ИЛИ случайное событие раз в 24–48 ч (кнопка «Дождик промочил Мурзика!»). Событие — не чаще 1 раза в день.

1. Мурзик грустный, носик зелёный, иконка 🌡 мигает. Все игры и кухня заблокированы (полупрозрачно + замочек).
2. Тап по иконке → **экран ветеринара** (весёлый кабинет: плакат со щенком и котом, бинты с сердечками).
3. **Последовательность**:
   - a. Термометр лежит на столе: drag к ушку → 2 сек измерения («пи-пи-пи») → на табло «38°».
   - b. Шкафчик с 3 полками: на средней — 3–4 ингредиента-лекарства (ромашка 🌼, мёд 🍯, витаминка ⭐, ягодка 🍓). Инструкция — пиктограмма: 2 предмета в миску. Drag 2 любых → миска: «бульк» с зелёным дымком → ложка. Drag ложки ко рту → Мурзик съедает, носик розовеет.
   - c. На лапке — «царапинка» (белая полоска). Пластырь с сердечком на ленте: drag на царапинку → наклеился. Тап «поцелуй» на пластырь → звёздочки, царапинка исчезла.
   - d. Ласка: 5 секунд поглаживания (как С8) → шкала «Спасибо!» заполняется.
4. Мурзик кувыркается, +12 монет, событие в Альбоме: стикер «Заботливый доктор».

#### С7. Ласка

1. Тап или плавный свайп по телу Мурзика (в комнате) → сердечки вылетают из точки касания, звук мурчания.
2. Каждое касание +4 к настроению. Кулдаун 0,5 сек между касаниями (антиспам).

#### С8. Мини-игра «Поймай рыбку» (аквариум)

- **Экран**: аквариум на весь экран, 5–8 рыбок плавают в разные стороны, пузыри.
- **Правило**: тап по рыбке → она «ловится» сачком, +1 монета, вылетает из аквариума в копилку (анимация). Обычная рыбка 1 монета, золотая (появляется 1 раз за раунд, быстрая) 3 монеты.
- **Раунд**: 30 сек. Таймер — песочные часы в углу. Итоговый экран: счёт, кнопки «Ещё раз» / «Домой».
- **Сложность по возрасту**: малыш — рыбки крупные (80 pt), медленные; большой — 55 pt, быстрые, золотая чаще.
- **Лимит**: 5 раундов подряд, потом перерыв 10 мин (уведомление-плашка «Мурзик хочет поиграть в другую игру!»).

#### С9. Мини-игра «Прыгалки по облачкам»

- **Экран**: небо, Мурзик стоит на облачке слева снизу, справа вверху — звезда.
- **Правило**: облачка мигают по очереди; тап по мигающему → Мурзик прыгает туда (анимация пружины), +1 монета и +1 к счёту прыжков. Пропустил/промахнулся — облачко гаснет, Мурзик остаётся; серия сбрасывается.
- **Цель**: достичь звезды за ≤ 15 прыжков. Звезда +5 монет.
- **Развитие**: счёт вслух озвучивается («раз! два! три!») — встроенное обучение счёту.

#### С10. Мини-игра «Музыкальные лапки»

- **Экран**: 5 больших клавиш-пианино (до-ре-ми-фа-соль) внизу, Мурзик сверху.
- **Правило**: тап по клавише → нота + Мурзик «поёт» соответствующее мяуканье (высота тона = нота). Одновременно клавиша подсвечивается.
- **Режимы**:
  - «Свободная игра» — просто играть.
  - «Повтори мелодию» (6–7 лет): игра показывает 3–5 нот подсветкой, ребёнок повторяет. Успех +5 монет.
  - «Запиши»: до 8 нот записываются, кнопка «Прослушать» и «Отправить маме/папе» (системный шеринг, без сбора контактов).

### 2.4. Режимы возрастной сложности

Выбирается при онбординге (иконки: соска/погремушка vs ранец) и в родительской зоне. Влияет на всё:

| Параметр | «Малыш» 3–4 | «Большой» 6–7 |

| Скорость падения шкал | ×0,6 | ×1 |

| Мелодии-повторения | нет | 3–5 нот |

### 2.7. Прогрессия и удержание

- **Уровень дружбы**: 10 уровней; растёт от totalCare (каждая забота +10 XP). Награды на уровнях: монетки, эксклюзивные стикеры, уникальная анимация (5 уровень — Мурзик подаёт лапу; 10 — танцует).
- **Альбом достижений**: 30+ стикеров в 4 разделах (Забота, Поварёнок, Игры, Дружба). Примеры: «Первая ванна», «10 уборок лотка», «Открыл все рецепты», «Сыграл мелодию из 8 нот», «Уровень дружбы 5».
- **Ежедневный календарь**: 7 клеток; каждый день входа — монетки (+10) и на 7-й день сундук (+30 и случайный наряд). Пропуск дня не сбрасывает серию, но не засчитывается.
- **События-ивенты** (регулярные обновления контента): «Первый снег» (шарфик, снежинки в окне), «День рождения Мурзика» (колпак, торт-рецепт), «Летняя гроза» (зонтик-наряд).

**Принцип**: только добровольный обмен, 9 сценариев, лимиты в таблице ниже (сброс в полночь, хранятся локально; серверного учёта нет — детское приложение).

| № | Точка | Условие показа кнопки | Награда | Лимит/день |
|---|-------|----------------------|---------|------------|
| R1 | Кухня, шаг «Пожарь» | блюдо готовится | готово мгновенно | 3 |
| R2 | Кухня, полка | не хватает ингредиента из выбранного рецепта | +1 ингредиент | 2 |
| R3 | Ежедневный сундук | при открытии календаря | сундук ×3 (+30 и стикер) | 1 |
| R4 | Мини-игры, экран итога | завершён раунд | второй шанс: продолжить со счётом | 2 |
| R5 | Комната, питомец болен | активно событие «Болезнь» | выздоровление без мини-игры | 1 |
| R6 | Любая завершённая забота | стандартное окно результата | монетки ×2 | 3 |
| R7 | Гардероб | на наряде нет замка (не куплен) | примерить на 60 мин | 2 |
| R8 | Магазин, вкладка «Комната» | любой товар | товар бесплатно | 1/2 дня |
| R9 | Кухня, книга рецептов | есть неоткрытые рецепты | случайный рецепт | 1 |

**Правила показа**:

- Кнопка приза — отдельная, яркая (радуга-обводка), с пиктограммой 🎁 и текстом-пиктограммой «посмотри — получи!». Никогда не путается с основным действием.
- Рекламный SDK: AdMob rewarded (G-rated, без персонализации) или Unity Ads (kid-safe). Fallback: если реклама не пришла за 3 сек — кнопка исчезает без ошибки.
- Защита от случайного нажатия: после тапа — подтверждение-модалка картинкой («Смотрим? Да / Нет»).
- После просмотра: закрытие только кнопкой «X» в углу; автоматически не закрывается.
- «Тихий час» (родительская настройка): в заданные часы все кнопки R1–R9 скрыты.
- Покупка «Без рекламы» ($2,99): кнопки исчезают навсегда, все лимиты сняты (без рекламы награды R1–R9 доступны по 1 разу в день бесплатно, чтобы не наказывать купивших).

## Часть 3. Техническое задание

### 3.1. Платформа и окружение

- **Платформа**: iOS 15.0+, iPhone only (SE 1-го поколения и новее). iPad — адаптивная вёрстка v2.
- **Ориентация**: портретная, без поворота.
- **Язык разработки**: Swift 5.9, SwiftUI (UI-слой) + SpriteKit (сцена комнаты и мини-игры) через `SpriteView`.
- **Архитектура**: MVVM. Модули: `Core` (состояние, время), `Scene` (комната, питомец), `Kitchen`, `MiniGames`, `Shop`, `Wardrobe`, `Vet`, `Toilet`, `Album`, `Settings`, `Ads`, `Analytics`, `Audio`.
- **Зависимости**: SPM. Только: Google-Mobile-Ads-SDK (или UnityAds), Firebase Analytics (Crashlytics — опционально). Никаких других трекеров.

### 3.2. Хранение данных

- `UserDefaults` — настройки (звук, возрастной режим, тихий час, реклама-выключена).
- `SwiftData` (iOS 17+) или CoreData fallback — состояние: таблицы `PetState` (шкалы, lastCalculated), `Inventory` (item_id, count), `OwnedItems`, `Recipes`, `Stickers`, `DailyCalendar` (streak, lastDay), `AdCounters` (date, scenario, count), `CareLog` (timestamps для аналитики дружбы).
- Пересчёт offline-decay при `scenePhase == .active`: `delta = min(elapsed, cap 8h)`, применить к шкалам, записать `lastCalculated = now`.
- Сброс прогресса: родительская зона → удаление всех хранилищ + подтверждение.

### 3.3. Аудио

- Все звуки — локальные файлы `.m4a`/`.caf`, без стриминга.
- Громкость: 3 канала (музыка, эффекты, голос) — родительский ползунок.
- Фоновая музыка: 3 трека (день, ночь, мини-игры), кроссфейд 2 сек при смене состояния.
- Озвучка фраз: 30+ коротких фраз диктора (женский голос, спокойный): «Мурзик голоден!», «Молодец!», «Пора убирать лоток!». Хранение имён питомца: фразы собираются из 2 частей (обращение + предикат), чтобы имя звучало естественно.
- `AVAudioSession`: категория `.ambient` (не перебивает музыку родителя, корректная работа с беззвучным режимом).

### 3.4. Графика и анимации

- **Стиль**: иллюстрации-«наклейки» 2048×2048 px source, экспорт в игру @2x/@3x; контур 4–6 pt на экране.
- **Питомец**: 10 состояний (см. 2.1), каждое — SpriteKit-атлас 8–12 кадров, 12 fps, пинг-понг или цикл.
- **Частицы**: сердечки, звёздочки, брызги, монетки — `SKEmitterNode` с параметрическими plist.
- **Анимации UI**: пружинные появления (`spring(response: 0.4, dampingFraction: 0.6)`), скейл-поп кнопок при тапе 0.95, скролл-магазин с параллаксом.
- **Виджеты**: домашний экран — не v1.

### 3.5. Интерфейс и навигация

- **Навигация**: `NavigationStack`, 4 корневые вкладки (Комната, Кухня, Игротека, Магазин) + модальные сценарии (Туалет, Ветеринар, Сон — оверлей без выхода из комнаты).
- **Палитра**: кремовый фон `#FFF6EA`, коричневый текст/контур `#5B3A29`, акценты: розовый `#FF6FA5`, мятный `#7FD8BE`, жёлтый `#FFD34D`, голубой `#7FB5F0`. Тёмная тема не поддерживается (игра дневная), ночной режим — внутриигровой.
- **Шрифты**: `Fredoka` (заголовки, кириллица есть), `Nunito` (текст). Размеры: кнопки-действия 22 pt, подписи 17 pt, минимальный текст 13 pt.
- **Hit-targets**: ≥ 64×64 pt для детских кнопок, ≥ 44 pt для системных.
- **Локализация**: русский v1; структура `Localizable.strings` с day-one.
- **Доступность**: VoiceOver на всех кнопках (пиктограммы с accessibility labels), Reduce Motion: отключает пружинки и частицы.

### 3.6. Рекламная интеграция

- **SDK**: Google Mobile Ads v11+, `GADRewardedAd`. Настройки: `GADMobileAdsConfiguration`, tagForChildDirectedTreatment = true, maxAdContentRating = G.
- **Контент**: только сертифицированные детские сети (Google сеть certified-for-kids).
- **Медиация**: не v1.
- **Обработка**: загрузка при входе в сценарий (preload), таймаут 3 сек, кэш 1 ролик на сценарий. Награда — только после `didEarnReward`, идемпотентность по `adNonce`.
- **Родительский выключатель**: флаг `adsDisabled` → скрытие всех точек, SDK не инициализируется.

### 3.7. Аналитика (анонимная, без ПД)

- События: `first_launch`, `pet_named`, `care_completed` (тип), `minigame_round` (игра, счёт), `recipe_unlocked`, `ad_shown` (сценарий), `ad_rewarded` (сценарий), `purchase_no_ads`, `session_length`, `retention_dN` (по local timestamps).
- Никаких IDFA, рекламных ID, геолокации. Firebase с настройкой «без персонализации».
- События уходят при наличии сети, очередь локальная.

### 3.8. Родительская зона

- **Вход**: удержание кнопки 3 секунды + вопрос «Сколько будет 7 + 5?» (4 варианта ответа).
- **Разделы**:
  1. Статистика (монетки, время в игре за день/неделю, сколько рекламы показано).
  2. Лимиты рекламы (переключатели по сценариям R1–R9, тихий час: время начала/конца).
  3. Возрастной режим («малыш»/«большой»).
  4. Звук (3 ползунка), озвучка вкл/выкл.
  5. Смена имени питомца.
  6. Покупка «Без рекламы» (StoreKit 2, restore purchases).
  7. Сброс прогресса (двойное подтверждение).

### 3.9. Производительность и батарея

- Цель: 60 fps на iPhone SE 2-го поколения; бюджет кадра < 12 ms CPU.
- Память: пик < 350 MB (атласы общим объёмом < 120 MB в распакованном виде).
- Фон: при `.background` все таймеры останавливаются, пересчёт только при возврате. Никаких фоновых задач и пушей в v1.
- Энергия: среднее потребление < 8% батареи за 30 мин игры (инструмент Xcode Energy Log).

### 3.10. Тестирование

- **Unit**: экономика (формулы монет, offline-decay, лимиты рекламы), рецепты.
- **UI-тесты**: онбординг, полный цикл заботы (5 потребностей), покупка, сценарий болезни.
- **Тест-группа**: 10–15 семей (дети 3–5 и 6–7) — наблюдение «молчаливого тестирования» (TestFlight), метрики: время до первой заботы, % детей, нашедших магазин без подсказки, эмоциональные реакции (фиксирует родитель).
- **App Review**: демо-видео, пометка «Made for Kids», родительская зона показана ревьюерам в примечании.
